# AI Venture Lab

Multi-agent AI platform for evaluating startup ideas.

## Stack

- Python
- FastAPI
- LangGraph
- PostgreSQL
- Redis
- LLM API
- Web Search
- Next.js
- React
- Langfuse
- OpenTelemetry
- Docker

## Development

```bash
cp .env.example .env
docker compose up --build
```

## Services
 - Frontend: http://localhost:3000
 - Backend: http://localhost:8000
 - Swagger: http://localhost:8000/docs
